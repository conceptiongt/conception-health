# Conception Health

App para consultorios y clínicas: pacientes, citas, expedientes (con fotos privadas), cobros,
reportes en Excel/PDF y suscripción (Básico / Max) con Recurrente.

- Frontend: React + Vite, publicado en Vercel (health.conception-gt.com)
- Base de datos y archivos: Supabase (proyecto `patienttrack`), con seguridad por consultorio (RLS)
- La versión anterior (un solo archivo HTML) quedó en `legacy/patienttrack-original.html`

```bash
npm install
npm run dev
```
