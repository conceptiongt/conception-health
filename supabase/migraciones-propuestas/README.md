# Migraciones propuestas

SQL que todavía **no** se ha aplicado. Cada archivo espera la aprobación explícita de la dueña (ver `CLAUDE.md`, regla 4).

- Un archivo por cambio: `AAAA-MM-DD_nombre.sql`, con un comentario arriba que diga qué hace, por qué y cómo deshacerlo.
- Al aprobarse y aplicarse, se mueve a `supabase/sql/`.
